我刚刚突然想到，我既不需要手动推导所有表达式，也不需要采样再拟合，我可以直接控制机器人在平面上扫出轮廓！

mode1 的内轮廓就是从l2=0到l2_max,theta_2一直保持当前长度下的最大值，此时工具末端扫过的就是内轮廓；然后保持l2 = l2_max,theta_2从theta2_max减到0，扫过的就是外轮廓。

mode 2内轮廓与mode 1 的外轮廓一样，外轮廓两条线组成，就是lr从0加到lr_max,theta2保持max不变，扫一条直线，第二条即lr保持max，theta2从max到0扫过的，得到第二条曲线；
就是假如theta2_max>pi/2，那么外轮廓应该是三条线，第一条是lr=0,theta2从max减到pi/2，然后保持，lr加到max，得到第二条，然后theta2从pi/2减到0，第三条。这个其实跟上面是一套逻辑，就是一个更泛化的流程。内轮廓也变成三条，我们把theta2从0到max扫出来的轨迹记作一种曲线，在lr=0和lr=max的时候分别有一条这样的曲线，我们记作Tau0,Tau1，就是相当于平移了一下，这两条曲线会产生交点p，那么从中轴出发，先沿着Tau0走到p点，然后沿着Tau1走到其末端(对应theta2_max，lr_max)，然后就是这个末端随着lr从max->0的过程扫出来的直线Tau2。但是其实还有一种情况，就是lr比较大，导致Tau0,Tau1其实并不会相交，那么就是Tau2与Tau0相交，轨迹只有Tau0 Tau2组成。其实这个就很像我们后面mode4会处理到的情况。我不知道这能不能合并为一个“大一统”的流程。

mode3，内轮廓有两段，第一段就是mode2的外轮廓的第二条曲线，第二段就是theta2保持max，theta1保持当前长度下的最大值，l1从0增加到l1max的过程中，末端扫过的曲线。外轮廓有两段曲线，第一段，l1,theta1保持max，theta2从max减到0，第二段是theta2保持0，theta1从max减到0。

mode4的外轮廓有三段，ls保持max，theta2保持0，theta1从0逐步增到min(pi/2, theta1_max)，这是第一段，然后theta1不变，ls逐渐减为0，这是第二段，然后其他不变，theta2从0加到max，这是第三段。然后内轮廓可能有两段，也可能有三段。如果是两段的话，其内轮廓就是mode3的内轮廓。下面是三段的情况：即mode3的第二条内轮廓中的横坐标的最大值，大于mode3的外轮廓与内轮廓的交点，那么这个末端在ls从0增加的时候会与这一条内轮廓产生交点，也就是说原本的内轮廓的第二条曲线的后面某一段会被这个交点上移过程中产生的直线覆盖。

mode 0 外轮廓和mode4一样，内轮廓就是先把所有mode的内外轮廓都画出来，从mode1内轮廓出发，沿着线往外走，遇到分叉路口就往右拐，直到与外轮廓相遇。
